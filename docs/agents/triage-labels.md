# Triage 标签

各 skill 以五个规范 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| skill 中的角色 | 本仓库实际标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完全规约化，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某个角色（例如「打上 AFK-ready 的 triage 标签」）时，使用上表对应的标签字符串。

如需修改右侧词汇以匹配实际用语，直接编辑右列即可。
